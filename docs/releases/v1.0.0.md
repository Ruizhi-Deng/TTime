# TTime Community 1.0.0

单用户本地版首个正式发布，基于 TTime 公开的 0.9.2 源码维护。本次使用 `main` 的最新代码重新构建，替换原有 1.0.0 发布文件。

## 下载与使用

- `TTime.Community-1.0.0-setup.exe`：Windows 安装版，可选择安装目录。
- `TTime.Community.1.0.0.exe`：Windows 便携版。
- `SHA256SUMS.txt`：两份程序的 SHA-256 校验值。

配置、密钥与历史保存在 `%APPDATA%/TTime Community/`。从官方 TTime 切换需要重新配置；此前 Community 版本的本地配置继续使用。首次配置后可选择自己的翻译源和提示词。

## 功能

- 删除账户、会员、设备绑定、云同步、使用统计及上游自动更新。
- 保留输入、划词、截图翻译、静默 OCR、快捷键、窗口钉住与本地历史；历史取消 30 条限制。
- 18 个翻译源：OpenAI / 兼容接口、DeepSeek、Gemini、智谱 GLM、百度、阿里云、Google API、有道、DeepL API、火山、小牛、彩云，以及 Google、DeepL、Bing、Bing 词典、TranSmart 内置源和离线 EcDict。
- AI 支持同类服务多个实例、独立接口与模型、自备密钥、流式输出和本地提示词库。各实例结果及历史独立保存。
- 四个 LLM 翻译源均提供 Request Arguments JSON 设置，每个实例独立保存，用于验证与翻译请求；支持 temperature、top_p 等接口参数，Gemini 使用原生 generationConfig 格式。
- 提示词变量 `{{text}}`、`{{source}}`、`{{target}}` 支持括号内空格，界面示例与实际规则一致。
- 本地 OCR 使用 PP-OCRv4 与公开多语言模型，提供文字、四角坐标、置信度和本地段落合并；支持 12 个语言或语系模型组。
- 中英混合和英文模型随程序提供，默认 OCR 可离线使用；其他模型首次使用时下载并缓存。
- 已移除 Azure OpenAI、Ollama、DeepLX、腾讯翻译君和 Papago 专用翻译接口。

## 验证

Windows 流水线验证本地历史、AI 请求与流式响应、真实 ONNX OCR 图片、应用编译、安装版与便携版打包，以及包内 OCR 模型完整性。用户已完成 Windows 交互实测；提示词与 Request Arguments 另经界面保存、参数传递和多实例测试。

真实付费 API 未逐一使用密钥实测；12 个 OCR 模型组已验证加载，部分语系使用 PP-OCRv3，其他语言准确率未逐语言评测。此次提供 Windows x64 包。

完整配置、构建和模型说明见仓库的 `docs/community-branch.md`。保留上游 TTime 及 PaddleOCR / RapidOCR 的许可与归属。
