# TTime Community 1.0.1

基于最新 `main` 构建，本次更新翻译窗口的缩放和定位行为。

## 更新内容

- 翻译窗口增加固定的右下角拖拽区，支持调整宽高。
- 手动调整高度后保持所选高度，长翻译内容在窗口内部滚动。
- 自动调整高度时跳过重复尺寸请求，并校正检测到的位置偏移，防止输入和结果更新导致窗口持续向左上漂移。

## 下载与使用

- `TTime.Community-1.0.1-setup.exe`：Windows x64 安装版，可选择安装目录。
- `TTime.Community.1.0.1.exe`：Windows x64 便携版。
- `SHA256SUMS.txt`：两份程序的 SHA-256 校验值。

此前 Community 版本的本地配置、密钥和历史继续使用，保存在 `%APPDATA%/TTime Community/`。
